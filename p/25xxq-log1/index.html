  • 教师和学生的个人信息和课程建立联表，可以互相查询

  • 统一退出登录或者修改密码后的默认 token_version 为随机 uuid

  • 修复批量删除用户导致课程被删的 bug

  • 统一了批量操作后端返回的 json 格式

  • 删减了身份验证冗余代码（装饰器已经验证过了，但是函数里又验证了一次）

  • 添加 /api/user_info 接口，可以返回用户的基本信息（学号，用户名，签名，注册时间，相关课程……）

  • 添加 /api/course_info 接口，返回课程的基本信息

  • 添加 /api/delete_course 接口，批量删除课程
