大致效果就是精简 & 美化一下命令行界面，另外加一点实用的功能。

效果图

安装 zsh

zsh 是一种 shell，比 bash 功能更强大。

  • Windows 建议在 wsl 下使用，很久之前我写过一篇配置 wsl 的教程，从 hashnode 迁过来了；
  • mac 默认 shell 就是 zsh，不用再装一次；
  • Linux 直接从包管理器里安装就行，如
    • Ubuntu (Debian 系) 
      1

      sudo apt install zsh
    • Arch 
      1

      sudo pacman -S zsh
      或者用 yay 和 paru 也行。

安装 oh-my-zsh

omz 是一个开源的管理 zsh 配置的框架，直接安装官网的提示装就行。

配置主题和插件

可以选择自己找，也可以选择抄作业

1
2
3
4

cd # 切到用户目录
git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions # 根据历史命令提示
git clone https://github.com/zsh-users/zsh-syntax-highlighting.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting # 关键词高亮
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k # 主题

p10k 主题用专门的命令行字体 (nerd fonts) 效果更好，可以去这里找，我一直用的是 Hack Nerd Fonts Mono，安装完字体之后在对应的终端配置里面修改即可。

编辑配置文件，建议用带图形界面的，比如 vscode，gnome-text-editor，kate，以 vscode 为例 (如果是熟悉命令行的佬可以随意，比如 vim，vi，nano)

1

code ~/.zshrc

改以下基础配置 (在文件中查找变量名，改对应的值即可)

1
2
3
4
5
6
7
8

ZSH_THEME="powerlevel10k/powerlevel10k" # 主题

# 插件
plugins=(
    zsh-autosuggestions
    zsh-syntax-highlighting
    git
)

source 一下配置文件

1

source ~/.zshrc

然后按照指引一步步初始化一下 p10k 主题。
